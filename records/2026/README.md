# 2026년 공개 기준 데이터

기준일: 2026-10-08. 화면 기준 커밋: `0580051`.

같은 날 후속 정정: 9·10페이지 크리에이터 이름은 담당자 확인에 따라 배손옥으로 반영했습니다. 크리에이터는 지인과 이웃의 사진을 수집하고 이야기를 구성하는 역할입니다. 정정 내용은 `archive-content.json`의 `editorial_notes`에 기록하며 원본 PDF는 변경하지 않습니다. 이후 웹폰트·문구 보완 버전은 Git 이력에서 확인합니다.

- `archive-content.json`: PDF에서 옮긴 작품 전체 원문.
- `motion_overlays.json`: 사진 위에 표시하는 발췌 글과 배치.
- `manifest.json`: 작품 순서, 영상 파일, 크기와 제작 정보.

이 폴더는 보존·복원용 사본입니다. 현재 제작기는 `output/video/archive-content.json`, `scripts/motion_overlays.json`, `output/video/pages-02-12/manifest.json`을 읽습니다. 정식 수정 뒤에는 이 기준 사본과 작품 대장을 함께 갱신합니다.

원본 사진·최종 PNG·AI 생성 결과는 포함하지 않습니다. 글과 배치는 공개된 `site/archive/`의 미디어를 이용해 다시 만들 수 있습니다. [복원 절차](../../docs/annual-update.md#2026년-글이나-배치만-수정할-때)를 참고하세요.
