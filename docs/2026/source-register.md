## 기관에서 확인·보완할 기본 문서

이 목록은 다음 담당자에게 인계할 관리 항목입니다. 현재 프로젝트에서 찾지 못한 문서를 이미 보유한 것으로 표시하지 않았습니다.

| 문서 | 현재 확인 상태 | 인계 시 정리할 내용 |
|---|---|---|
| 2026년 사업계획서·운영 일정 | 확인되지 않음 | 공식 사업명, 목적, 기간, 담당, 추진 일정 |
| 작품 선정·원문 최종 확인 기록 | 확정 웹 데이터는 보유, 별도 확인 기록은 미확인 | 작품 대장과 원문 확인일·수정 이력 |
| 사진 제공·공개 범위 확인 자료 | 확인되지 않음 | 작품별 기관 내부 관리번호·보관 위치 |
| 결과보고서·실적 자료 | 확인되지 않음 | 실제 운영 결과·참여·전시 실적 및 근거 |
| 예산·정산 문서 | 확인되지 않음 | 사업 운영상 필요한 경우 기관 문서와 연결 |
| 전시 협조·홍보 최종본 | 관련 HWP·포스터 보유 | 최종본·시행본 여부 확인 |
| 기관 공식 로고 원본 | 공식 벡터 원본 미확인 | 추후 확보 시 웹 편집본 교체 여부 판단 |
| 영구 백업·인수인계 확인서 | 이 문서 작성만으로 완료 여부 확정 불가 | 보관 위치·백업일·담당자 확인 |

사업계획·결과보고의 수치나 승인·동의 상태를 추정해 채우지 않습니다. [연간 인수인계 양식](../templates/year-handover.md)을 기관 내부 사본으로 작성해 연결합니다.
