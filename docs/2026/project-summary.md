## 콘텐츠 구성과 기준

- 크리에이터는 활동을 통해 지인과 이웃의 사진을 취합하고 스토리텔링을 하는 역할입니다. 이름별 전시의 이름은 사진 수집·이야기 구성 담당자를 나타내며, 사진 제공자나 개인 기억의 주인공을 뜻하지 않습니다.
- 2026-10-08 담당자 확인으로 9·10페이지 크리에이터 이름을 배손옥으로 정정했습니다. 원본 PDF는 보존하고 웹 데이터·작품 대장에 정정을 반영했습니다.

- 작품 원문: `아카이빙작품_출력.pdf` 1~12페이지에서 이름·제목·전후 설명·장소·촬영 시기를 화면 판독해 옮겼습니다.
- 날짜는 원문 범위를 유지했습니다. 예를 들어 2페이지 현재 촬영 시기는 `2026년`으로 기록되어 있습니다.
- 작품 설명의 1인칭 표현은 수집된 이야기의 원문으로 유지합니다. 이를 크리에이터 본인의 경험으로 설명하지 않습니다.
- 확정 데이터: 프로젝트의 `records/2026/`에 원문·발췌 글·미디어 목록 사본을 보존합니다.
- 작품별 정보와 파일 연결은 [작품 대장](works.csv)에 있습니다. CSV는 편집용 웹 데이터가 아닌 관리용 출력입니다.
- 첫 화면 원본 11장과 PDF 작품 번호는 직접 대응하지 않습니다.

확장 영역은 영상 연출을 위한 편집 결과이며 당시 건물·지형을 고증한 기록이 아닙니다. 과거에 없는 현재 건물·사물을 생성하지 않는 기준을 적용했습니다. 서로 다른 촬영 방향의 사진은 원래 풍경을 보존하고 정확히 겹친다고 표시하지 않습니다.

관련 이력은 로컬의 `output/video/generation-02-12.json`, 각 페이지의 `alignment.json`, 1페이지 `outpainted/README.md`에 보존합니다.

## 화면·미디어 규격

- 전시 화면: WebP 두 장과 HTML 글을 동기화. 과거→현재 5초, 역방향 5초. 총 10초 왕복 반복.
- 다운로드: 무음 H.264 MP4 12개, 각 5초·30fps·150프레임.
- 큰 사진: 1페이지 1070×1000, 확장 적용된 2~12페이지 중 해당 작품은 1152×960, 원본 유지본은 1152×822~840. 정확한 크기는 manifest에 기록.
- 모바일: 640px 사진 제공, 가까워지는 작품부터 로딩, 화면 밖 움직임 정지, 모션 줄이기 설정 지원.
- 첫 화면: 전체 사진 배경, 우측 문구, 재생/정지·장면 선택·좌우 넘기기·글로 읽기. 전환 중 확대가 초기화되지 않도록 처리.
- 기관 마크: 제공 스크린샷에서 나무·글자를 추출한 투명 WebP. 공식 벡터 원본은 별도 확보하지 않음.
- 첫 화면 마크는 투명 배경을 유지하며, 사진과 구분되도록 나무·글자 외곽에 밝은 테두리와 은은한 그림자를 적용합니다. 전시 하단 마크·글·문의처는 가운데 정렬입니다.
- 2026-10-08 후속 보완: 전시 제목·서정 문구·작품 설명에 Noto Serif KR 기반 웹폰트를 자체 제공. Mac과 Windows의 기본 명조체 차이를 줄이고, 실제 문구만 WOFF2로 압축. 원본 출처·해시·라이선스는 `site/assets/fonts/`에 기록.

## 재제작과 보존

1. `site/`와 workflow: 현재 공개 사이트 복구에 필요한 최소 산출물.
2. `records/2026/`와 운영용 `scripts/`: 공개 미디어를 이용한 글·배치 재생성에 필요한 자료.
3. `doc/`와 `output/`: 사진 편집·프레임·영상 재제작 및 원자료 보존에 필요한 자료.
4. `docs/2026/`: 작품·원자료·파일 목록과 프로젝트 설명.

원본과 제작 자료는 GitHub 사본에 모두 포함되어 있지 않습니다. [원자료·문서 대장](source-register.md)과 [파일 관리 기준](../file-management.md)을 함께 인계합니다.
